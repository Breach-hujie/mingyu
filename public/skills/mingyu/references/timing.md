# 时间范围、边界与应期

本资料在需要阶段、窗口或应期时读取。时间先作为事实定位，再作为术式推断结果；每个窗口同时写出粒度、起点、终点、所属上层和触发证据。

## 统一时间包络

采用半开区间 `[start, end)`：起点属于当前阶段，终点进入下一阶段。日期级窗口写当地日期和时区，节气/交运/交限/换局等边界写精确时刻；资料只到日期时，终点使用下一日 00:00 的当地时间并标明日期级精度。

每个时间判断使用以下记录：

```text
窗口：……至……（粒度：年/月/日/时/阶段）
上层背景：……；触发层：……；边界：……；证据：……；待核验节点：……。
```

时间顺序按当地时区、历法和节气口径确定。历史夏令时、真太阳时、子初/子正、冬至换年和农历闰月会改变边界时，保存换算前后值，并将影响的柱、宫、卦、局或窗口写清楚。

## 时间层级

| 粒度       | 常见资料                           | 合适表达                        |
| ---------- | ---------------------------------- | ------------------------------- |
| 长周期     | 元会运世、宅运、时代周期           | 主题与阶段转折，附历史/现实锚点 |
| 十年或阶段 | 八字大运、紫微大限、奇门分运、宅运 | 起止时刻、阶段主调和跨界层级    |
| 年         | 流年、太岁、值年卦、岁运           | 年界与主题触发，保留所属上层    |
| 月/节气    | 流月、六步气、月建、月将           | 节气月界和月内前后段            |
| 日/时      | 六爻日辰、奇门时局、三传、牌阵当下 | 起盘时刻、事件窗口和可观察节点  |

更细粒度必须有相应计算事实或明确现实锚点。卦象、牌象和签文只有阶段语义时，使用顺序和窗口，不强行换算为某日。

## 阶段边界协议

1. 先列上层阶段，再列目标窗口；窗口始终保留所属上层。
2. 交运、交限、节气、冬至、换局、换卦、站留转向或宅运交界发生在目标范围内时，将边界时刻单列。
3. 边界时刻起归入新层；事件恰在边界前后发生时，分别引用前层余势与后层触发。
4. 起止资料只到年龄、年份或大致月份时，保留阶段顺序，写明精度和补算后可能调整的层级。
5. 多阶段事件使用事件簇：一个事件簇可关联多个阶段索引，每一阶段单独写触发、表现和验证节点。

## 奇门终身局分运时间

四柱分限、十年干支大运、九宫巡行和符使交替分段是四种独立模型。十年干支大运按八字交节起运合参奇门本命宫：记录顺逆、精确起运时刻、起运年龄、起运规则、每步干支、开始时间和结束时间；起运前童限作为单独阶段。交运时刻属于新运，交运年份或目标窗口跨界时并列前后两运的证据、表现和核验节点。

## 应期表达与复核

先回答时间问题的层级：是“何时具备条件”“何时发生转折”还是“何时结果落地”。再写窗口与触发因素，区分推测窗口和已知日期。一个窗口至少带一项可观察节点，例如职位变化、消息到达、签约、搬迁、症状记录、关系状态或候选日期结果。

复核时检查：起止是否明确；时区/历法是否一致；窗口是否带上层背景；边界是否按半开区间处理；应期是否来自该方法取用链；跨阶段事件是否保留多层；精度是否超过资料能力。无法精确时回到阶段和条件表达。
