# 盘面事实与证据账

本资料在路线确定后读取。解读的每条判断都经过“事实—理法—推断—核验”链条；不同层级的材料各自保留，合参时再对齐。

## 五层证据

| 层级        | 内容                                               | 写法                       | 作用                 |
| ----------- | -------------------------------------------------- | -------------------------- | -------------------- |
| L1 输入事实 | 用户资料、原始卦局/牌签、地点、时间、现实事件      | 原值、单位、口径、取得时间 | 确定主体和边界       |
| L2 计算事实 | 四柱、宫位、星曜、卦爻、门星神、三传、飞星、节气等 | 盘面原文与计算口径         | 提供可复核结构       |
| L3 传统依据 | 经典条文、派别规则、象义和术式语法                 | 原文要点、版本或传承口径   | 说明为何这样取用     |
| L4 关系推断 | 生克、合冲、相位、结构组合、阶段触发               | 从哪些 L1/L2/L3 推出       | 形成结论与条件分支   |
| L5 现实核验 | 已发生事件、客观状态、后续可观察节点               | 日期、结果、观察方式       | 检查模型是否贴合问题 |

同一结论至少同时引用一项 L2 计算事实和一项 L3 理法；若属于现实判断，再接一项 L1 或 L5。只有象义而缺少盘面结构时，结论保持为可能性描述，并列出需要补齐的事实。

## 证据账模板

每个重点判断记录一行：

| 判断 | 事实         | 传统依据  | 推断路径               | 时间/条件          | 核验节点           | 资料状态 |
| ---- | ------------ | --------- | ---------------------- | ------------------ | ------------------ | -------- |
| ……   | L1/L2 的原值 | L3 的取法 | 从事实到判断的中间关系 | 适用范围和触发条件 | 已发生或待观察日期 | A/B/C 级 |

示例：

```text
判断：某阶段工作职责先扩张后定型。
事实：大运干支与命局某十神形成明确生克；目标年份出现对应流年触发。
依据：所用流派对该结构的取用条文。
路径：结构改变资源/责任关系 → 先出现任务增量 → 条件满足后形成稳定职位。
时间：以交运时刻为阶段起点，目标年份按节气月展开；交界月份保留两层。
核验：职位、项目范围或收入结构在对应窗口出现可记录变化。
```

事实、依据和推断使用不同句式。计算结果直接引用；传统规则写明适用派别；推断使用“因此/若/在……条件下”；核验只描述可观察事实和时间点。

## 证据强弱

强度由四项组成：

1. **可重复**：同一输入和口径能重现盘面；
2. **结构贴合**：取用对象在方法中是主证据，而非边缘象；
3. **时间对应**：结论落在方法可支持的时间粒度；
4. **现实回验**：已有节点与推断方向相符。

四项分别写在证据账中，不合成虚构分数。缺一项时说明缺失原因和会缩小的结论范围；同一方法内部主证据优先于辅助象，跨方法时依据主体与时间尺度对齐。

## 冲突矩阵

发生分歧时按下面顺序排查，并保留可解释的分支：

| 冲突来源 | 核对项                                               | 输出方式                                |
| -------- | ---------------------------------------------------- | --------------------------------------- |
| 输入冲突 | 出生/起盘时间、地点、历法、时区、性别、主体身份      | 列出版本与影响到的柱位/宫位/局式        |
| 计算口径 | 真太阳时、节气换界、起局/起卦法、飞盘/转盘、派别算法 | 写明采用口径，另一口径作为条件分支      |
| 取用差异 | 用神、体用、世应、类神、主客或牌位权重               | 各自沿本法链条判断，再找共同事实        |
| 时间尺度 | 本命与事件局、年度与月日时、宅运与居者阶段           | 分开回答，不让细尺度覆盖长尺度          |
| 资料层级 | 原始盘面、传统解释、现实描述之间的矛盾               | L1/L2 保留原值，L3/L4 写分支，L5 待核验 |

每个分支使用同一格式：

```text
条件 A（口径/事实）：……
对应盘面证据：……；判断：……；时间窗口：……。
条件 B（口径/事实）：……
对应盘面证据：……；判断：……；时间窗口：……。
决定分支的可观察信息：……。
```

## 空亡、空宫与资料缺口

空亡、空宫、无相位或牌位缺牌等“空”首先是盘面事实，再结合方法规则判断其作用。说明它改变的是力量、落实速度、信息可得性还是应期表达，并说明填实、触发或补资料条件。空象不直接等同结果定性。

资料缺口按三类写：

- **定位缺口**：无法确定主体、时刻、地点或基本盘面；先补采；
- **细层缺口**：本命可读但宫位、时柱、流月或精确应期受影响；先给上层结论与条件；
- **核验缺口**：结构已清楚但缺少现实节点；写出可观察的阶段事实和复核时间。

## 发送前证据复核

逐条检查重点结论：主体是否一致；原始输入是否保留；盘面值是否与采用口径一致；取用对象是否符合术式语法；传统依据是否能解释中间关系；时间窗口是否有起止和粒度；条件分支是否写出触发条件；资料缺口是否影响结论层级。未通过的判断回退到上层事实，不补造盘面。
