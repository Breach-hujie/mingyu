# 解读推理复核

本资料在形成结论或发送任务书前读取。它检查推理链是否真实落在主体、问题、时间、证据和术式语法上，使用语义场景复核而非只看方法标题。

## 通用九项复核

1. **主体**：当事人、关系双方、房屋、地点或年度身份稳定；代称与资料对应。
2. **问题**：结论逐句回应核心事项；复合问题已拆成子问题。
3. **时空**：日期、时刻、地点、时区、历法、真太阳时和节气口径一致。
4. **资料**：原始盘面、牌阵、签谱、候选日期或宅向保留；缺项标出影响层级。
5. **取用**：用神、体用、世应、类神、主题宫、用神宫、主客或牌位有明确理由。
6. **证据**：每条重点判断同时有盘面事实和传统依据，推断中间关系可复述。
7. **条件**：流派、口径、主体感受或资料版本有差异时，条件 A/B 与触发信息完整。
8. **时间**：窗口有起止、粒度、上层背景、触发证据和核验节点；边界按 `[start, end)`。
9. **输出**：结论、依据、展开、时间、核验层次清楚；任务书脱离界面仍完整。

## 语义场景验收

使用真实式任务句验证方法路线能落到证据和时间，而不是只命中标题：

| 场景                                     | 预期文字证据                                             |
| ---------------------------------------- | -------------------------------------------------------- |
| “出生时刻接近节气，想看未来十年职业转折” | 同时出现月令/交节口径、运限层级、窗口边界和回验节点      |
| “交运当天签约，前后两运怎么判断”         | 出现精确交运时刻、前后两层、事件簇和各自触发             |
| “六爻问面试，卦有动爻又逢旬空”           | 出现世应/用神、动变、旬空填实、成败先于应期              |
| “两人关系一方时刻未知”                   | 出现双方证据账、精度不对称、交互相位/宫位与条件分支      |
| “房屋朝向只有罗盘范围，想定装修日期”     | 出现测量口径、形势/理气分层、候选日期与补测项            |
| “黄历跨立春选开业日”                     | 出现节气换年、候选日同口径比较、主事人关系和日界         |
| “皇极经世解释某历史阶段”                 | 出现元会运世/值年卦、历元、历史事实独立核验和时间层级    |
| “灵签问婚事”                             | 只展开签号、签题、签诗、典故与题意映射，保持原签资料层次 |

每个场景至少核对三项语义证据：方法取用、时间/条件边界、现实核验。缺少其中一项时回到证据账补齐，而不是增加术语数量。

## 任务书净化

发送前检索任务正文：

- 有 `【当前时间】`、`【问题】`、`【任务】`、`【盘面资料】`、`【传统依据】`、`【输出要求】`；
- 盘面资料、传统依据和问题条件可独立阅读；
- 方法指南被转换为自然语言任务，工程、项目、接口、内部路由和来源实现留在操作层；
- 普通任务的五段结构可见，灵签资料范围准确；
- 精确数字、日期和结论都能回指证据账；
- 术数表达与现实资料层次清楚，时间精度和条件分支相称。
