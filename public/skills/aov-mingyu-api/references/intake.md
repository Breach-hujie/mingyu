# 问题卡与资料门槛

本资料在每次解读的最前面读取。目标是把自然语言问题变成一张可检查的问题卡，让主体、事项、时间范围和证据来源在后续步骤保持稳定。

## 问题卡

按以下顺序记录，已经明确的内容直接写入，暂缺内容标成“待补”：

| 项目       | 记录方式                                                             |
| ---------- | -------------------------------------------------------------------- |
| 核心事项   | 一句话写成“谁在什么时间范围内，面对什么具体问题”                     |
| 主体       | 当事人、关系双方、团队/机构、住宅、地点或年度；分别记录身份与代称    |
| 关系身份   | 本人/伴侣/家人/客户/合作方/事件对象，以及双方对称资料                |
| 目标       | 判断趋势、解释结构、比较选项、寻找时间窗口、回验已发生事实或查阅原典 |
| 指定术式   | 用户明确指定的术式优先；未指定时依路由矩阵选择主法                   |
| 时间范围   | 本命、阶段、年度、月日时或一次事件；写出当地日期、时区和节气口径     |
| 地域与环境 | 出生地、起盘地、候选地点、住宅坐向和实际使用场景                     |
| 已知事实   | 已发生事件、关键日期、结果和可供回验的节点，按时间排序               |
| 输出粒度   | 结论、依据、条件分支、窗口、盘面解释、传统原文或对照表               |
| 资料状态   | 完整、部分可用、待补；写明缺项影响到哪一层判断                       |

问题卡完成后，给它一个简短的内部标题，后续盘面、传统资料和现实核验都挂在同一张卡下。补充问题先判断是澄清原卡，还是新建另一张卡。

## 主体锁定

先区分“被分析的人/物”和“提问的人”。个人本命以当事人出生资料为主体；占问以本次起卦/起课/抽牌的人与事项为主体；合盘把双方各自建档，再建立互动卡；择日以事项、地点和主事参与人为主体；宅居以房屋、坐向、居住者和使用目的组成主体。

同一对话出现“我、他、公司、这套房”等多个指代时，先建立代称表。历史记录只能补充已确认事实，新的主体资料、关系状态和目标时间范围要在问题卡中重新确认。

## 资料分级

### A 级：可以进入完整路线

盘面所需的日期、时刻、地点、历法、时区和方法参数齐全，且问题与时间范围清楚。可取得主方法的结构、动态和应期证据；传统资料只在改变取义时读取。

### B 级：部分回答并保留条件

存在一项会影响细层的缺口，但仍有稳定的主体和主问题。例如八字有年月日而时辰待考，可谈前三柱和阶段大势；星盘缺出生时刻，可谈行星与相位而暂缓宫位和轴点；宅向只有大致方向，可谈形势并把理气结论作为待测条件。输出中写明可用层级、未覆盖层级和补资料后会改变的判断。

### C 级：先完成澄清或只做资料整理

主体、核心事项、起盘时间或原始牌卦签资料尚未确定，多个问题混成一问，或时间口径冲突到无法定位盘面。先将已知内容整理成待确认项；拥有可核对的原始资料后再进入取用链。

资料门槛的产物包括：可用层级、缺项清单、缺项影响、最小补采顺序和可先行回答的范围。缺失资料保持空缺，等待用户或可靠资料补齐。

## 时空一致性

出生和起盘资料同时保留“当地钟表时间”和“用于排盘的时间口径”。历史日期优先核对当时有效的时区、夏令时和历法；经度修正或真太阳时参与排盘时，记录换算前后时刻与是否跨日、跨时辰。节气是月令、流月、换年或运限边界时，记录具体交接时刻和采用的历法。

同一资料出现明确时区与地点推导时区不一致，建立“明确时区”和“地点推导”两个分支，分别写明会改变的柱位、宫位或窗口。已有完整盘面时先核验口径，再将盘面事实作为本次解读的输入，原始资料和复核意见并列保留。

## 澄清顺序

1. 主体与关系身份；
2. 一句话核心事项；
3. 目标时间范围和当地时空；
4. 指定术式或可接受的主法；
5. 影响取用的最小缺项；
6. 已发生节点与希望核验的事实；
7. 输出粒度和传统资料深度。

每次澄清只解决会改变路由或结论层级的一项。资料达到 B 级时先形成可用结论和条件分支，达到 A 级后再补细层；资料仍为 C 级时保持问题卡，不把猜测写入盘面。
