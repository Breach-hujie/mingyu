# 资料提供方与事实保真

本资料在需要排盘、动态扫描、传统原文或任务书组装时读取。提供方只负责取得和整理事实，解读层负责取用、条件和结论；两层之间用统一的事实契约连接。

## 六项能力

| 能力       | 输入                         | 产物                                 | 解读层用法                   |
| ---------- | ---------------------------- | ------------------------------------ | ---------------------------- |
| 能力发现   | 方法身份、意图、资料级别     | 可用方法、时间粒度、细节范围         | 路由确定主法与可用层级       |
| 盘面计算   | 规范出生/起盘/环境资料       | 带口径的原始盘面与计算时间           | 作为 L2 事实，保留原值       |
| 事实标准化 | 原始响应、用户盘面或手工资料 | 统一日期、干支、宫位、牌签和地点表达 | 建立证据账，保留转换前后值   |
| 动态扫描   | 主体、目标时间范围、粒度     | 运限、流年、流月、事件簇和边界       | 按 `timing.md` 展开时间层    |
| 传统资料   | 方法、取用问题、原典版本     | 条文要点、版本与适用条件             | 作为 L3 依据，改变取义时再读 |
| 任务书组装 | 问题卡、事实、依据、方法指南 | 自包含自然语言任务书                 | 只保留问题资料与传统依据     |

## 事实契约

每个产物至少包含：主体、方法、时间、地点/时区、历法/算法口径、原始计算事实、动态范围、精确度、资料版本和异常说明。结构化资料与展示文案分开，转换过程保留可回查的原值。

时间资料特别记录：当地钟表时间、固定时区或时区标识、真太阳时换算、节气/冬至/交运边界、是否跨日或跨时辰。动态资料记录上层阶段、当前层、起止时间和窗口粒度。

## 响应模式与细节

常规解读使用紧凑资料，同时保留会改变取用的字段；事实复核、跨流派比较和研究任务使用完整资料。请求只需要任务书时，直接取得已核实事实和任务段，避免把未使用的方法或完整计算过程混入当前任务。

## 异常与降级

取得失败时保留问题卡、已确认输入和已有盘面，记录失败环节与未取得内容。可以用现有事实完成上层解读时，明确可用层级和补采项；无法定位关键主体、时刻或原始卦牌签时，先输出资料整理结果。异常本身属于操作事实，与术数吉凶分开。

## 来源与传统资料

计算事实、用户提供的现成盘面、传统文献和现实核验分别归档，注明时间、版本和适用条件。引用固定签谱、易林或皇极资料时保留原文标签、卷页或校勘状态；未确认字形、断句和版本差异进入条件分支。

## 方法结构映射

提供方返回资料后，按 `reading-workflow.json` 的方法结构组织：`intent` 决定目标，`inputs` 对照资料门槛，`scope` 决定动态范围，`evidence` 决定取用链，`timing` 生成时间包络，`conditions` 保存口径分支，`review` 生成复核项。上述结构服务于加载和人工组织，给在线 AI 的正文只呈现自然语言内容。

具体能力、方法参数和资料表见 [`providers/aov-mingyu.md`](providers/aov-mingyu.md)。
