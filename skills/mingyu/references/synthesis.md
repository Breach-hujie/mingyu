# 多术式合参与分歧处理

本资料只在问题确实需要两种以上方法时读取。合参的对象是同一主体、事项和时间范围内的证据；各术式先完成独立判断，再对齐时间尺度与现实事实。

## 合参矩阵

在合并结论前建立一行或多行矩阵：

| 子问题 | 主法 | 主法结论与证据 | 辅法 | 辅法补充 | 时间层级     | 共同事实 | 分歧条件 | 待核验 |
| ------ | ---- | -------------- | ---- | -------- | ------------ | -------- | -------- | ------ |
| ……     | ……   | L2/L3/L4       | ……   | ……       | 年/阶段/事件 | ……       | ……       | ……     |

主法负责回答该子问题，辅法只填补约定维度。命理方法提供承载与背景，事件卦局提供当下态势，奇门提供时空/主客，星盘提供心理与关系结构，择日和宅居提供日期/环境条件，原典和签谱提供材料语境。对应关系随问题调整，并记录在矩阵中。

## 六步流程

1. **确认同题**：检查主体、核心事项和时间范围是否相同；不同事项先拆卡。
2. **独立取证**：按每个方法自己的取用、结构、动态和应期链完成判断，保留原始证据账。
3. **对齐尺度**：将本命、运限、年度、事件局、牌阵当下、宅运和宏观周期放在各自时间层，不让细层替代上层。
4. **提取共同事实**：只合并跨方法都指向、且能回指盘面或现实资料的事实；共同事实与解释分开写。
5. **展开差异**：按输入口径、流派、主体感受、取用对象、时间边界和资料精度排查分歧，形成条件 A/B。
6. **落到核验**：每个共识或分支附可观察的事件、状态或日期，写明尚未覆盖的资料。

## 分歧等级

| 等级        | 表现                                  | 处理                                 |
| ----------- | ------------------------------------- | ------------------------------------ |
| D1 口径差异 | 时区、节气、起局/起卦、派别或历元不同 | 先统一口径；无法统一时并列盘面与窗口 |
| D2 尺度差异 | 本命长期结构与当刻事件局方向不同      | 解释为背景与当前触发的层次关系       |
| D3 取用差异 | 用神、世应、主客、牌位或主题宫不同    | 写出各自取用理由和影响到的结论       |
| D4 资料差异 | 原始资料、计算结果、现实描述互相不符  | 保留原值，标明可信层级和补核事项     |
| D5 真分歧   | 口径和资料一致，方法仍给不同方向      | 分别呈现证据与条件，使用后续节点复核 |

合参结论按“共同事实—方法解释—条件分支—时间窗口—核验节点”组织。方法数量、符号强度或多数意见不构成独立证据；分歧本身也可以是问题所需的信息，例如长期承载与当前机会的差别。

## 资料不对称

双方合盘、命盘与事件卦局、居者与宅向常出现资料精度不对称。精度高的一方承担相应细层结论，精度低的一方保留上层或条件表达；二者的共同部分单独列出。一个方法缺资料时，矩阵中写“未覆盖”并说明补齐后会影响的判断，不以另一方法代填。

## 合参输出模板

```text
共同事实：……（盘面/传统/现实依据）
主法判断：……（取用链与适用时间层）
辅助判断：……（只补充约定维度）
条件分支：……（口径、主体、时间或资料条件）
时间窗口：……（起止、粒度、上层背景）
现实核验：……（已发生节点或待观察事实）
资料缺口：……（影响的层级和补采顺序）
```

完成矩阵后再读取 `output.md` 组织语言；需要检查主体、边界和回指关系时读取 `reasoning-checks.md`。
